# Contact form: active native HTML integration

**Real Formspree endpoint:** `https://formspree.io/f/mrpqagaa`

**Important:** The Send enquiry button is immediately available; no JavaScript endpoint configuration is needed. The form uses `action="https://formspree.io/f/mrpqagaa" method="POST"` and native browser submission. The visitor is taken to the Formspree response page on submission.

To test: publish the files, open https://kahmedstats.github.io/KA/#contact, fill all required fields, accept consent and click Send. Look for the Formspree success page, then check **Formspree → Submissions**. In Formspree settings/workflow verify the inbox and notification preferences. If submissions appear but no email arrives, check inbox verification and notification settings/spam filters. If a Formspree error page appears, follow that message (and look at form quota or protection settings).

No receiving email address is included in the published code. Do not put any email password or account token in GitHub.
