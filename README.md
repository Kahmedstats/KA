# Kawsar Ahmed — Research Homepage (`Kahmedstats/KA`)

Live site: [https://kahmedstats.github.io/KA/](https://kahmedstats.github.io/KA/)

## Repository Root Files
- `index.html` — Page shell and hidden-email inquiry modal with submit button
- `style.css` — Light, Paper, and Dark themes + hero scene backdrop styling
- `data.js` — Editable profile data (`window.SITE`), multilingual strings (`en`, `zh`, `es`, `fr`), and links
- `app.js` — Safe DOM rendering, language switcher, theme/font controls, and inquiry form submission
- `campus-scene.jpg` — Scene photo used in the hero background (upload to repository root)
