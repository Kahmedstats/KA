# Add your profile photo to the KA GitHub Pages website

**Required image filename:** `me profile.jpg`

**Required GitHub path:** `assets/me profile.jpg`

- On GitHub, open `https://github.com/Kahmedstats/KA/tree/main/assets`.
- Click **Add file → Upload files**. Select your own JPG portrait and ensure its filename is exactly `me profile.jpg`.
- Commit changes. Your header will automatically show the portrait as a 50px circular crop.
- You do not need to change `index.html` or any script after the picture upload.
- If the picture is missing, a neutral avatar icon appears; the site still works.
- This ZIP deliberately does not contain a made-up portrait; it includes `assets/profile-placeholder.svg` for the fallback.
